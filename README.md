# guessing-game-java
A simple command-line guessing game written in Java
The program picks a random number between 1 and 100, and the player tries to guess it.
## Features
- Random number between 1–100
- Feedback if the guess is too low or too high
- Keeps asking until the correct number is guessed
- Shows how many tries it took to win
## Example
Enter your guess:
50
The number is too low
Guess again
75
The number is too high
Guess again
62
Correct!! You guessed it in 3 tries!
